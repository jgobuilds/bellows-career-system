# Target Profile Analysis

Read the job description like a recruiter wrote it (they did) and reverse-engineer what they're actually screening for.

## Extract these

**1. Must-haves vs. nice-to-haves.**
Requirements language ("required," "must have," "X+ years") vs. preferences ("bonus," "nice to have," "ideally"). The must-haves are where keyword match and knockout questions live. Miss a must-have and no formatting saves you.

**2. Their exact terminology.**
Capture the *company's own words* for the role, the skills, and the outcomes. If they say "experimentation platform," use that, not "A/B testing infrastructure." If they say "data governance," use it verbatim. Semantic ATS matching bridges some synonyms, but an exact match still scores higher than a bridged one, and the recruiter's saved search uses their words. Build an acronym/full-form pair list for anything that has one (ML/Machine Learning, ETL/Extract-Transform-Load, LLM/Large Language Model) and include both forms in the resume, since different parsers index different forms.

**3. Seniority signal.**
Does the title/scope map to the user's level? Data leader targeting "Director, Data Platform" vs. "Head of Data" vs. "VP Analytics" — each implies different scope (team size, budget, board exposure). Workday in particular weights title-match to seniority heavily. If the user's current title undersells their scope, surface the scope (team size, budget) prominently to compensate.

**4. What the role optimizes for.**
Every leadership role has a hidden thesis. Read for it:
- **Build (0→1):** stand up a function/team/platform from scratch. → select bullets about founding, first hires, greenfield.
- **Scale (1→n):** grow an existing function. → select bullets about headcount growth, process, reliability at scale.
- **Turnaround:** fix a broken/underperforming team. → select bullets about remediation, rebuilding trust, cleanup.
- **Governance/trust:** compliance, data quality, stakeholder trust. → select bullets about governance, quality, exec buy-in.
Match the user's selected bullets to the thesis. A build role wants a builder's resume.

**5. Knockout risks.**
Location, work authorization, hard years-of-experience floors, required certs/clearances, degree requirements. Name these to the user directly — they're pass/fail and no resume craft changes them. Better the user knows before spending effort.

## Output
A short brief: the thesis, the ranked must-haves, the terminology/keyword list (with acronym pairs), the seniority read, and any knockout flags. This brief drives Phase 4 selection.
